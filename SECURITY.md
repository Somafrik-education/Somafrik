# Politique de sécurité — Somafrik

Canal de signalement : **security@somafrik.app**

Politique détaillée : [docs/project/SECURITY.md](docs/project/SECURITY.md)

## Branches prises en charge

| Branche | Statut |
|---------|--------|
| `develop` | Intégration / préproduction |
| `main` | Production (releases autorisées par le CTO) |
| Autres branches | Aucune garantie de correctif |

## Signaler une vulnérabilité

1. **Ne pas** ouvrir une issue GitHub publique décrivant un exploit, ni publier un PoC avant correctif.
2. Écrire à **security@somafrik.app**.
3. Fournir uniquement les informations minimales nécessaires à la reproduction.
4. **Ne pas** joindre de données personnelles inutiles.
5. Respecter la divulgation responsable.

Délais de remédiation cibles (effort, pas un SLA) : voir [docs/project/SECURITY.md](docs/project/SECURITY.md) §9.

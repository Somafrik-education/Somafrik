# Web Somafrik V2

Cette application accueillera progressivement les surfaces web migrées vers Somafrik V2.

## Règles de fondation

- consommer uniquement les contrats publics de l'API V2 ;
- réutiliser le langage visuel validé sans importer directement les modules de `web/` ;
- migrer une capacité métier à la fois avec preuve de parité ;
- conserver l'application actuelle comme runtime jusqu'au cutover validé.

Aucun écran utilisateur n'est déplacé dans le lot de fondation.

# Mobile Somafrik V2

Cette application accueillera progressivement les parcours mobiles migrés vers Somafrik V2.

## Règles de fondation

- consommer uniquement les contrats publics de l'API V2 ;
- préserver SecureStore, HTTPS, le fail-closed RBAC et la synchronisation non destructive ;
- ne pas importer directement les fichiers de `Mobile/` ;
- garder l'application Expo actuelle active jusqu'à la parité validée.

Aucun parcours mobile n'est déplacé dans le lot de fondation.

# Assets des guides utilisateurs

Ce dossier est réservé aux **captures d'écran réelles de Somafrik en exécution**.

## Interdits

- maquettes ou images recréées ;
- captures du BackOffice legacy ;
- captures d'une version non identifiée ;
- données personnelles réelles ;
- mots de passe, PIN, tokens ou secrets temporaires ;
- images modifiées de manière à faire apparaître un bouton ou un état absent du produit.

## Sous-dossiers cibles

- `web/` : captures de la plateforme Web ;
- `mobile/` : captures de l'application Mobile.

Git ne versionnant pas les dossiers vides, ils seront matérialisés lors de l'ajout de la première capture validée.

Avant tout ajout, vérifier la ligne correspondante dans `../CAPTURES-METIER.md`.
